# 일본어 튜토리얼 (히라가나)

히라가나·카타카나·인사·숫자·JLPT 단어를 배우고 퀴즈로 복습하는 정적 웹 앱입니다.

원본: [wj6742aol-web/hiragana-tutorial](https://github.com/wj6742aol-web/hiragana-tutorial)

## 온라인

게시된 앱은 로컬 실행 없이 항상 열려 있습니다: https://hiragana-tutorial.apps.grok.bot

## 로컬 실행

```bash
npm start
```

브라우저에서 `http://127.0.0.1:5540` 을 엽니다.

Windows에서는 기존 PowerShell 서버도 사용할 수 있습니다.

```powershell
powershell -File serve.ps1
```

## 사용법

1. 홈에서 튜토리얼(히라가나, 카타카나, 인사 등)을 고릅니다.
2. **배우기**에서 글자·단어를 확인합니다.
3. **퀴즈**로 읽기·뜻을 점검합니다.
